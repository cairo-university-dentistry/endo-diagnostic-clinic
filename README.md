# ENDO // Diagnostic Clinic — Vertical Slice v0.1

A dependency-free first playable prototype for the planned Endodontic Diagnosis project.

## Included
- Premium landing with Game Mode / Gold+ choice
- Stylized clinic blockout
- Patient 01 history dialogue
- First-time incomplete-history warning
- Clinical mouth/examination scene
- Visual / Percussion / Palpation evidence capture
- Gold+ Present Illness and Clinical Examination micro-sections
- Game → Gold+ → exact-screen return bridge
- localStorage progress
- Responsive mobile layout
- GitHub Pages-friendly relative asset paths

## Run locally
Because this prototype has no build step, you can open `index.html` directly.
For best behavior, serve the folder with any simple static server.

## GitHub Pages
Upload the contents of this folder to a repository and publish from the repository root (or `/docs` if you move the files there). All paths are relative.

## Important
This is the **vertical-slice foundation**, not the final 3D build. The clinic is deliberately rendered as a lightweight CSS isometric blockout so interaction, visual language, state restoration, and the Game ↔ Gold+ bridge can be tested before committing to production 3D assets.

Scientific copy in this slice is based only on the supplied `Diagnosis 2026.pdf`.
